# Linux-SetupHelper MVP 実装タスク

## この文書の目的

Ubuntu Server 24.04 LTS の初期設定手順を、安全かつ決定的に生成する MVP を完成させるための実装バックログである。タスクは原則として依存順に並べ、1件を1回の変更・レビューで完了できる大きさにする。

## 進め方

- チェックボックスは、完了条件と検証をすべて満たしたときだけ完了にする。
- `依存` に未完了のタスクがある場合は、原則として着手しない。
- **安全性重要**タスクは、対応する回帰テストが成功するまで完了扱いにしない。
- 実行できない検証がある場合は、理由、未検証範囲、残るリスクを記録する。
- MVP範囲または安全性ルールを変える必要が生じた場合は、実装を止めて利用者の承認を得る。
- 新しい依存関係は、必要性、オフライン動作、保守性、ライセンスを確認してから追加する。

## ガードレール

### 対象

- Ubuntu Server 24.04 LTS のみを対象にする。
- sudo可能な管理ユーザー、SSH公開鍵認証とsshd安全化、UFW、unattended-upgradesを扱う。
- 出力は、利用者が内容を理解しながら手動実行する画面手順、Markdown手順書、個別設定ファイル、バージョン付き設定JSONとする。

### 実装しないもの

- サーバーへの接続、検出、設定解析、移行、修復、コマンド自動実行。
- Ubuntu 24.04 LTS以外、クラウドVM、Docker、Webサーバー、DBの構築。
- パスワード、秘密鍵、APIキーの入力、生成、保存。
- 任意コマンド、生の設定ファイル、自由形式スクリプトの入力。
- 全処理を一括実行するシェルスクリプト、生成AIによるコマンドや設定の自由生成。
- バックエンド、DB、アカウント、実行時の外部API・解析・広告・テレメトリ・CDN・外部フォント。
- localStorage等への自動保存。

### 生成停止条件

- 許可リストで検証できない入力がある。
- 有効なSSH公開鍵がない状態でパスワード認証を無効化しようとしている。
- sudo可能な管理ユーザーがない状態でrootログインを無効化しようとしている。
- SSHポート変更時に、新ポートのUFW許可が同じ計画に含まれていない。
- その他、SSHロックアウト、権限喪失、情報漏洩、設定破損につながる組み合わせがある。

## フェーズ2: 純粋TypeScript生成エンジン

責務は `入力スキーマ → 正規化・検証 → 安全性ルール → 中間モデル → 出力` の順に分離する。細かなファイル名は実装時に決めてよい。

### [ ] T-020 入力スキーマと設定JSONを実装する

- **依存:** T-003、T-010

- **完了条件:** 未知のキー、未対応バージョン、型違反、範囲外値を安全な日本語エラーで拒否する。秘密情報や自由形式入力を受け付けない。
- **検証:** 有効値、境界値、未知値、旧新バージョン、悪意ある文字列のVitestを実行する。

### [ ] T-021 正規化を実装する

- **依存:** T-020
- **作業:** 同値入力を一意の内部表現へ変換し、暗黙の現在時刻、乱数、外部状態に依存しない正規化を実装する。
- **完了条件:** 同じ意味の入力は同じ正規化結果になり、正規化済み入力は不変として扱える。
- **検証:** 同値性、冪等性、入力非破壊、環境非依存性のVitestを実行する。

### [ ] T-022 専用レンダラーを実装する

- **依存:** T-020
- **作業:** ユーザー名、SSH公開鍵、SSHポート、タイムゾーン等を用途別に検証・描画する。ユーザー入力をシェルや設定ファイルへ直接補間しない。
- **完了条件:** 各レンダラーが許可された値だけを出力し、引用符・改行・制御文字等による注入を拒否する。
- **検証:** 正常値、境界値、注入文字列、改行、Unicode混在のVitestを実行する。

### [ ] T-023 **安全性重要** SSHロックアウト防止ルールを実装する
